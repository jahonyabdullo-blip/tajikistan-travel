# Tajikistan Travel — frontend demo

Премиальный адаптивный сайт на HTML5, CSS3 и Vanilla JavaScript.

## Запуск
Распакуйте архив и откройте `index.html` в браузере. Для разработки удобно использовать VS Code + Live Server.

## Структура
- `index.html` — разметка и контент.
- `style.css` — цвета, типографика, адаптивная сетка, анимации.
- `script.js` — переключение RU/EN/TJ, фильтры, мобильное меню, галерея, сохранение карточек и форма-демо.
- `assets/images/` — папки для ваших фотографий.

## Замена изображений
Найдите в `index.html` атрибут `src` нужного изображения и замените URL на локальный путь, например `assets/images/hero/pamir-main.jpg`. В галерее также обновите `data-full`, чтобы увеличивалась большая версия фотографии. При ошибке загрузки показывается SVG-заглушка.

## Важно
Фотографии сейчас загружаются с Unsplash и требуют интернет. Отели и рестораны — демонстрационные концепции, не реальные предложения. Планировщик не рассчитывает маршруты и не отправляет данные. Язык хранится в `localStorage`.
